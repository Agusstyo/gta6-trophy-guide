An offline GTA 6 trophy guide and tracker: all 55 official PS5 trophies with a progress checklist that saves in the browser, export and import, filters, a spoiler setting, a roadmap to the platinum, missable flags, and a guide to each trophy in our own words with its sources cited.

## Run it

```sh
node --experimental-strip-types main.ts   # writes the guide to /output
```
